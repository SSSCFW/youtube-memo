# YouTube Memo - Brave拡張機能

YouTube動画にオフラインメモを追加できるBrave/Chrome拡張機能です。

## 機能

- ✨ YouTube動画ごとにメモを保存
- 📝 歌詞やメモを簡単に記録
- 👁️ メモの表示/非表示切り替え
- 💾 オフラインで動作（localStorageに保存）
- 🌓 ダークモード対応

## インストール方法

### Braveブラウザの場合

1. `brave://extensions/` にアクセス
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このフォルダ（youtube-memo）を選択

### Google Chromeの場合

1. `chrome://extensions/` にアクセス
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このフォルダ（youtube-memo）を選択

## 使い方

1. YouTubeの動画ページを開く
2. プレイヤーの右側にメモエリアが表示される
3. テキストエリアにメモ（歌詞など）を入力
4. メモは自動的に保存される
5. 「メモを非表示」ボタンでメモを隠すことができる

## ファイル構成

```
youtube-memo/
├── manifest.json      # 拡張機能の設定ファイル
├── content.js         # メイン機能のスクリプト
├── styles.css         # UIのスタイル
└── README.md          # このファイル
```

## 注意事項

- メモはブラウザのlocalStorageに保存されます
- ブラウザのデータを削除するとメモも消えます
- 各動画のIDに基づいてメモが保存されます

## カスタマイズ

- メモエリアの高さは `styles.css` の `min-height` で調整可能
- ボタンの色やスタイルも `styles.css` で変更可能
