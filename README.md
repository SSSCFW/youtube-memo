# YouTube Memo — Brave / Chrome 拡張機能

YouTubeの動画ごとにメモを保存する拡張機能です。1つの動画に複数のメモページを作り、手動または動画の再生時間で切り替えられます。

## 機能

- 動画ごとのメモ・ページタイトルを自動保存
- ページの追加、削除、順序の入れ替え、前後移動、一覧からの選択
- ページごとの開始時刻による自動切り替え（動画ごとに有効／無効を保存）
- 複数ページではメモ下部とページタイトル右端の両方に「戻る」「前へ」を表示（1ページなら非表示）
- 詳細設定内でページ一覧・追加・削除・順序変更・時刻設定・「横幅をリセット」を開閉
- 動画とメモの間の縦グリップを左右にドラッグして2列の幅を変更し、動画ごとに自動保存
- メモを非表示にすると右側の関連動画リストを空け、検索マイクの右隣に「メモを表示」を配置
- メモ欄の高さの保存、ダークモード対応
- YouTube内のページ遷移、遅れて生成されるレイアウト、非表示の古いサイドバー、画面の作り直しに対応

メモは拡張機能の `chrome.storage.local` に保存します。YouTubeへの送信や、外部サービスとの同期は行いません。従来の1動画1メモは、その動画の1ページ目として引き継ぎます。

## インストール

1. このリポジトリをダウンロード、またはクローンします。
2. Braveでは `brave://extensions/`、Chromeでは `chrome://extensions/` を開きます。
3. 「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` があるフォルダを選びます。

ビルドや `npm install` は不要です。開発用のNode.jsは、テストを実行するときだけ必要です。

### 以前のバージョンから更新する場合

1. 既に読み込んでいる拡張機能と同じフォルダを更新します。Gitで取得している場合は `git pull` を実行します。
2. 拡張機能の管理画面でYouTube Memoの再読み込みボタンを押します。
3. **更新の反映のため、既に開いているYouTubeタブを一度再読み込みします。**

拡張機能を削除して入れ直す必要はありません。保存済みメモを引き継ぐため、同じ拡張機能を更新してください。

## 使い方

### メモとページ

1. YouTubeの通常の動画ページ（`/watch?v=...`）を開きます。
2. 動画右側に表示されるメモ欄に入力します。右側の領域が非表示の場合は、動画下の表示可能な領域を使います。
3. メモ欄の下にある「詳細設定」から「ページを追加」で新しいページを作成します。
4. 2ページ以上になると、詳細設定を閉じたままでも下部の「戻る」「前へ」で切り替えられます。
5. 詳細設定内のページ一覧で対象ページを選び、「上へ移動」「下へ移動」で順番を入れ替えられます。

**ページが1つの間はタイトル欄を表示しません。** 2ページ以上になると、メモ本文の上にページタイトルの入力欄が表示され、各ページに別々のタイトルを付けられます。タイトルを空欄にしたページは、一覧では「ページ 1」などと表示します。

「このページを削除」で現在のページを削除できます。本文またはタイトルがある場合は確認が出ます。最後の1ページは削除できません。ページの順序を入れ替えても、本文・タイトル・開始時刻はそのページと一緒に移動し、メモ内容は変わりません。

「メモを非表示」を押すと右カラムからメモ枠を取り除き、YouTube上部の音声検索ボタンの右隣に「メモを表示」が現れます。そこを押すとメモを元の場所に戻せます。

### 動画とメモの横幅調整

通常のデスクトップ動画ページでは、動画とメモの間（メモ左端）に縦のグリップが表示されます。左右へドラッグすると**右側のメモ・関連動画カラムの幅**が変わり、動画側は残りのスペースに合わせて伸縮します。グリップを選択して左右の矢印キーでも微調整できます。

- 変更は `memo_sidebar_width_<動画ID>` に保存し、動画ごとに個別に復元します。
- 詳細設定の **「横幅をリセット」** で、その動画だけYouTube標準のカラム幅に戻せます。
- メモを非表示にしている間は調整を解除して関連動画一覧を通常の幅に戻し、「メモを表示」で設定済みの幅を復元します。
- 狭いウィンドウ、縦に積まれるレイアウト、シアターモード、フルスクリーンでは調整を適用しません。保存値は維持されるため、通常の2カラム表示に戻ると再適用されます。

### 再生時間による自動切り替え

自動切り替えは初期状態では無効です。次の手順で動画ごとに設定します。

1. 各ページを選び、「このページの開始時刻」に時刻を入力します。
2. 必要に応じて「現在の再生時間を設定」を押すと、その時点の秒数を設定できます。
3. 「再生時間で自動切り替え（この動画）」を有効にします。

| ページ例 | 開始時刻 | 表示される再生位置 |
| --- | --- | --- |
| イントロ | `0:00` | 0秒から29秒まで |
| Aメロ | `0:30` | 30秒から1分19秒まで |
| サビ | `1:20` | 1分20秒以降 |

- `90`、`1:30`、`0:01:30` は、いずれも90秒を表します。小数秒も入力できます。
- 新しいページの開始時刻は空欄です。空欄のページは手動で選択します。
- 再生位置を早送り・巻き戻しすると、その位置に対応するページに切り替わります。
- 最初の開始時刻より前は1ページ目を表示します。同じ開始時刻が複数ある場合は、並べ替え後のページ一覧で後にあるページを使います。開始時刻そのものは並べ替えで変更しません。
- 自動切り替え中に手動で別のページを選ぶと、次の時間区間に入るまでそのページを保ちます。
- 本文・タイトル・開始時刻の入力欄にフォーカスがある間や、日本語変換中は自動切り替えを保留します。入力欄から離れると現在の再生位置に追従します。
- 設定は動画ごとに保存されるので、動画Aだけ有効、動画Bは無効といった使い分けができます。

### 保存について

本文、タイトル、ページ構成、開始時刻、自動切り替え設定、最後に選択したページは自動保存します。読み込み中は編集を待機し、保存・読み込みに失敗した場合はメモ欄の下にエラーと「再試行」を表示します。

旧形式の `memo_<動画ID>` の内容を1ページ目に読み込み、編集後は `memo_pages_<動画ID>` に新形式で保存します。旧形式のキーは削除しません。高さは従来どおり `height_<動画ID>` を使います。

## 開発・テスト

Node.js 22.7以降を使用します。

~~~bash
npm ci
npx playwright install chromium
npm test
~~~

Node.jsの単体テストとPlaywrightによるChromiumテストを実行します。テストではYouTubeのレイアウトを模したページと保存APIを使い、実際のDOM、表示／非表示、クリック、入力、動画イベント、遅延読み込み・書き込みを検証します。公開中のYouTube全レイアウトや個別のブラウザプロファイルを網羅するものではありません。

既存のChromiumを使う場合は、実行ファイルを `YOUTUBE_MEMO_CHROMIUM_PATH` で指定できます。`YOUTUBE_MEMO_SCREENSHOTS` にディレクトリを指定すると、狭い画面でのライト／ダーク表示のスクリーンショットを保存します。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | 拡張機能の設定 |
| `memo-model.js` | 保存データの互換性、ページと時刻の処理 |
| `content.js` | 画面への表示、ページ操作、動画イベント、保存 |
| `styles.css` | メモ欄と設定のスタイル |
| `icons/` | 拡張機能のアイコン |
| `test/` | 単体・ブラウザ回帰テスト |
